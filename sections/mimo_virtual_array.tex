\section{MIMO and the Virtual Array}

Angle estimation requires many spatially separated measurements, but physical elements are costly. Since only the \emph{sum} of the transmit and receive path lengths appears in the measured phase, transmitting from several separated elements synthesizes a larger effective array.

\begin{definition}[Transmit and Receive Arrays]
$N_{tx}$ transmit elements at $p^{tx}_0, \dots, p^{tx}_{N_{tx}-1}$ and $N_{rx}$ receive elements at $p^{rx}_0, \dots, p^{rx}_{N_{rx}-1}$, along a common 1-D array axis.
\end{definition}

\begin{definition}[Virtual Array]
For a target at angle $\theta$, pair $(i, j)$ measures round-trip phase
$$\phi_{ij} = \frac{2\pi}{\lambda}\left(p^{tx}_i + p^{rx}_j\right)\sin\theta,$$
identical to a single physical element at $p^{tx}_i + p^{rx}_j$. The \emph{virtual array} is the set of these sums,
$$\{p_m\} = \left\{p^{tx}_i + p^{rx}_j \ : \ 0 \leq i < N_{tx}, \ 0 \leq j < N_{rx}\right\}, \qquad N_a = N_{tx}N_{rx}.$$
\end{definition}
Against a reference element at the origin, the extra path length is $p^{tx}_i\sin\theta$ on transmit and $p^{rx}_j\sin\theta$ on receive; the round trip accumulates both.

\begin{remark}[Uniform Virtual Array (ULA)]
Receive elements spaced $d$ and transmit elements spaced $N_{rx}d$ apart make the sums $p^{tx}_i + p^{rx}_j$ tile a uniform linear array of $N_{tx}N_{rx}$ elements at spacing $d$, with no gaps or repeats.
\end{remark}

\begin{remark}[Resolution Gain]
The angular resolution $\Delta(\sin\theta) = \frac{\lambda}{N_ad}$ is set by the \emph{virtual} aperture $N_ad$, so MIMO gains a factor of $N_{tx}$ over the receive array alone while costing only $N_{tx} + N_{rx}$ physical elements.
\end{remark}

\begin{definition}[TDM-MIMO]
Exactly one transmit element is active per chirp, cycling through the $N_{tx}$ elements in order, so each transmitter's contribution is separated by its time slot. One pass through all $N_{tx}$ is a \emph{loop}, and a frame is $N_d$ loops.
\end{definition}

\begin{definition}[Ramp Repetition Interval]
Time $T_r$ between consecutive chirps of any transmitter, including idle time. This differs from the chirp duration $T$, which covers only the active sweep.
\end{definition}

\begin{remark}[Alternatives to TDM]
Doppler-division multiplexing (DDM) instead transmits from all elements simultaneously, separating them by (coded) Doppler offset. This avoids the $N_{tx}$-fold reduction in $v_{\max}$, at the cost of additional separation processing.
\end{remark}
